# Student Performance Analysis Using Python

## Project Overview
This project analyzes student academic performance and attendance using Python. It focuses on data cleaning, exploratory data analysis (EDA), and data visualization to understand student results, subject performance, department performance, and attendance patterns.

## Objectives
- Clean and prepare student performance data.
- Identify missing values, invalid entries, and duplicate records.
- Analyze student marks and pass/fail percentages.
- Compare average marks across subjects and departments.
- Explore student attendance patterns.
- Identify top-performing students.
- Present findings through charts and visualizations.

## Technologies Used
- **Python**
- **Pandas** — Data manipulation and cleaning
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualization
- **Jupyter Notebook** — Development environment

## Project Files
- `Student_performance_Analysis.ipynb` — Contains data cleaning, analysis, visualizations, and findings.
- `Student_Performance_Messy.csv` — Original dataset used for data cleaning.
- `requirements.txt` — Lists the required Python libraries.

## Project Workflow
1. Load and inspect the dataset.
2. Explore columns, data types, and data quality.
3. Handle missing values and invalid entries.
4. Standardize categorical values and inspect duplicates.
5. Perform exploratory data analysis.
6. Visualize academic performance and attendance.
7. Summarize key findings and conclusions.

## Key Analysis Areas
- Student pass and fail distribution
- Average marks by subject
- Department-wise academic performance
- Student attendance distribution
- Top-performing students
- Missing-value and duplicate-record analysis

## How to Run the Project
1. Clone or download this repository.
2. Install Python and Jupyter Notebook, if not already installed.
3. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

4. Keep the CSV dataset in the same folder as the notebook.
5. Open the notebook in Jupyter Notebook.
6. Run the notebook cells in order.

## Key Findings
The notebook evaluates the overall pass percentage, strongest subject by average marks, department with the highest average marks, attendance patterns, and top performers. Refer to the notebook's final findings section for the calculated results.
